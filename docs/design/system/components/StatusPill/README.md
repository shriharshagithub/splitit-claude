A small pill that states a balance direction or a settlement status in words. Colour supports the word; it never replaces it.

- Balance: `owed` ("you are owed ₹450.00"), `owe` ("you owe ₹1,200.00"), `settled` ("settled up").
- Settlement: `pending` ("Pending"), `pending` again for marked-paid ("Waiting for Ravi to confirm"), `done` ("Completed"), `declined` ("Not received").
- Provide: the full phrase. Amounts inside use the amount family.
