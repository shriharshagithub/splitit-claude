The action control, in five variants. Use one `primary` per screen for the main action, pinned to the bottom and full width (`block`). Use `upi` only for Pay via UPI. Use `secondary` for the alternative ("Paid in cash"), `quiet` for low-emphasis links, and `danger` for delete and "Not received".

- Provide: a label in sentence case that names the action, and `disabled` plus a helper line when the action is unavailable.
- Height is 48px (`sm` is 36px, for inline use in rows such as "Settle up").
- Do not put two `primary` buttons on one screen. Do not use `upi` for anything but opening a UPI app.
